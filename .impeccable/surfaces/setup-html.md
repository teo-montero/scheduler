# Workspace setup

Mode: Operate. Reuses the established Study Space visual system.

Four steps: UCL timetable URL; external Moodle sign-in link; one-way commute in minutes and home/campus study preference; recurring activities with days and times.

This is a UI-only prototype as explicitly requested. Navigation, native input validation, choice controls, and add/remove activity rows are interactive. No storage, authentication, timetable import, scheduler calls, or completion flags. Enter through the sample workspace setup link or setup.html. Finishing or skipping returns to dashboard.html. No claims that a connection has succeeded.

Responsive: desktop progress rail and form; mobile four-step strip above the form. Existing palette, controls and system typography; no new media or dependencies.
